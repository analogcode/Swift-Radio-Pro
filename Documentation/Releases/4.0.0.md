# Swift Radio v4.0.0: SwiftUI and Swift 6

Swift Radio's stations list, Now Playing, station information and About screens have been rebuilt in SwiftUI, preserving the familiar station cards, artwork, marquee titles and popup player.

## Important changes

- **SwiftUI navigation and player:** Rebuilt screen navigation, popup presentation and options-sheet transitions, including returning directly to the player after sharing.
- **Playback reliability:** Improved coordination of loading, playback and audio-session activation. File scrubbing resumes playback, while a later Pause, Stop or station selection takes precedence over an older seek.
- **Consistent station state:** Phone and CarPlay share playback and catalog state. Stale artwork and metadata cannot replace the current station's presentation.
- **CarPlay catalogs:** Added loading/retry states and pagination for larger catalogs within CarPlay's list and navigation limits.

## Additional notable updates

- Added `SwiftRadioCore`, a local package containing playback, catalog loading, artwork and system-media integration.
- Adopted Swift 6 language mode and expanded core, real-engine and UI regression coverage.
- Integrated published **FRadioPlayer 0.4.0**, **LNPopupUI 4.0.1** and **LNPopupController 4.5.12**.
- Expanded configuration, architecture and localization documentation; refreshed the sample station catalog.

## Also on Android

Our Android counterpart, [Swift Radio Android](https://github.com/fethica/Swift-Radio-Android), uses Kotlin, Jetpack Compose and the same station JSON format. We've added [compose-popupbar](https://github.com/fethica/compose-popupbar) for its expandable Now Playing bar and full player, bringing a similar popup experience to the iOS version's [LNPopupUI](https://github.com/LeoNatan/LNPopupUI), which wraps [LNPopupController](https://github.com/LeoNatan/LNPopupController).

## Requirements and upgrading

Requires **iOS 17+** and **Xcode 26.6+**. Existing forks should port custom UIKit controllers/coordinators into the new SwiftUI structure. The station JSON format remains compatible; branding and content remain configurable through `Config`, assets and the String Catalog.

The attached IPA is unsigned. It can be sideloaded using [AltStore](https://altstore.io) or [Sideloadly](https://sideloadly.io), which re-sign it with your own Apple ID, or the project can be built directly in Xcode.
